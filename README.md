Readme
O objetivo do projeto é auxiliar Sr. João avaliar com as informações levantadas de cada loja, com o faturamento, categorias mais vendidas, avaliações dos clientes, produtos mais vendidos e frete médio, para que assim ele tenha uma opção de qual loja seja vendida! Meu objetivo através dos dados enviados por arquivos CSV extrair dados para essa análise. Os códigos extraídos das informações das quatro lojas foram organizados, por sua vez esses dados em DataFrames forma trabalhados em biblioteca Pandas. • Segue estrutura dos dados: Estrutura dos Dados: O dataset inclui as seguintes informações: Produto e Categoria: Itens vendidos e suas classificações. Preço e Frete: Valores das vendas e custos associados. Data de Compra e Local: Informações temporais e geográficas. Avaliação da Compra: Feedback dos clientes. Tipo de Pagamento e Parcelas: Métodos utilizados pelos clientes. Coordenadas Geográficas: Localização das transações. • Com dados enviados obtivemos o índice de analise abaixo: Índice de analise: A. Faturamento Total de Cada Loja B. Vendas por Categoria C. Média de Avaliação por Loja D. Produtos Mais e Menos Vendidos E. Frete Médio por Loja F. Atividade Extra. Todas as analise foram processadas com ajuda de Python, em todas elas temos números calculados e gráficos obtidos desses números. Por último foi demonstrado em uma atividade extra, que é uma Análise de Desempenho Geográfico.
